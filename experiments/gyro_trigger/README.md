# 从前半窗的运动决定是否需要角速度

在仓库根目录执行 `python -B experiments/gyro_trigger/run_gyro.py`。两库分别拟合和验证，不涉及跨库训练。人员沿用动作预算实验，UCI 13 人训练、8 人验证，MotionSense 16 人训练、4 人验证。各模型均为在训练人员上标准化的类别均衡逻辑回归。每种输入对三轴和模长计算均值、标准差及平均绝对一阶差。

窗口 128 点，50 Hz。决策只见前 64 点的总加速度。全窗加速度分类器与「全窗加速度＋后半窗角速度」分类器的预测在决策后选择。另有连续读取全窗角速度的对照。训练人员按人做四折，产生前半窗模型的折外置信度。训练人员置信度分位数确定阈值；另一种规则用岭回归估计后半窗融合能否纠正加速度分类结果。目标预算 25% 或 50% 指训练集阈值，在新用户上实际读取率会变化。按人随机打乱实际触发掩码 200 次，与相同请求次数的随机策略比较。

25% 目标下，MotionSense 按不确定度选择时逐人平均实际触发 19.52%，macro-F1 为 85.53%，同次数随机为 81.05%；UCI 分别为 27.67%、86.98%、87.15%。结果仅为离线信号访问仿真，总加速度由发布的 body/user acceleration 与重力相加得到。原窗口相互重叠，本实验没有测量设备上的连续占空比、唤醒时延或能量。
