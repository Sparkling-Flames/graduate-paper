# 换一种手机佩戴环境，少量示范应该采哪些动作？

用 UCI HAR 的腰部手机与 MotionSense 的前裤袋手机做双向迁移。在目标环境请两位志愿者贡献少量指定动作的带标签窗口，评估同一环境的其他人。五类活动是走路、上楼、下楼、坐、站。我们用现有标签模拟按指令采集，不使用待评估人员的信号或标签适配模型。

## 30 窗开发结果

表中是五类逐人 macro-F1（%）。前三种联合训练共享相同的分类器、示范人和总标注窗数。

| 方法 | 腰部 UCI → 裤袋 MotionSense | 裤袋 MotionSense → 腰部 UCI |
|---|---:|---:|
| 两域联合，只采走、坐、站 | 61.17 | 38.80 |
| 两域联合，采走、坐、站、上楼，省下楼 | 64.47 | 48.99 |
| 两域联合，五类各采 6 窗 | 65.13 | 61.00 |
| 只用目标的 30 窗从头训练五分类器 | 67.00 | 63.38 |
| 只用源域，无目标标签 | 25.15 | 21.87 |

腰部为目标时，把部分平地预算转给楼梯，线性模型平均增加 22.20 个百分点。七对示范者的差值均为正（16.3 至 28.8），八位验证者各自平均也均为正。三类平地方案中，上下楼两类的 F1 均为 0；五类均采后分别为 51.5% 和 65.7%。源域已含两种楼梯的标签。裤袋为目标时，该对照平均只增加 3.96 个百分点，八对示范者中五对提高，四位验证者中三位提高。五类均采后，上下楼的 F1 提高，走路 F1 却从 59.9% 降到 40.2%。增加标注总量至 60 窗，两方向的五类对平地优势分别为 24.77（腰部目标）和 4.70（裤袋目标）个百分点。

在分层分类器中，30 窗只采坐站、只采动态、五类均采的结果分别为 49.72%、42.12%、64.92%（裤袋目标）和 31.07%、50.34%、58.97%（腰部目标）。这项比较还涉及替换不同的分类分支，应优先用上表中的同算法对照解释采集策略。

**随机森林复核。** 在观察到线性结果后，按相同示范窗和权重训练 48 棵树、最大深度 8，关闭 bootstrap 以保证每棵树看到稀少的目标窗。30 窗时由平地转为五类，腰部目标从 42.10% 升到 60.05%（七对示范者全部提高），裤袋目标从 59.24% 升到 65.60%（八对中的七对提高）。60 窗时分别从 43.03% 升到 60.23%、从 58.94% 升到 68.65%。腰部目标下，即使没有目标楼梯示范，森林的下楼 F1 仍达 43.03%，所以线性模型的零分有模型依赖性。仅用目标示范标签拟合的森林在 30 窗上分别为 57.84%（腰部）和 65.83%（裤袋）；树模型统一使用按源域缩放的输入。

**选题判断。** 优先研究「新环境必须补采哪些动作」，把能否超过仅用少量目标标签直接训练的模型作为迁移算法的检验。两个迁移方向来自同一对数据集，手机设备、人群及信号处理也随佩戴方式改变；不能由此推断腰部位置导致楼梯更难迁移。能进一步区分解释的数据是同一批人同步佩戴多个传感器的 [RealWorld HAR](https://www.uni-mannheim.de/dws/research/projects/activity-recognition/dataset/dataset-realworld/)。本次还没有在该库训练或评价。

## 实验设计

- UCI 只读取官方训练集。13 人可做源域训练或目标域示范，另外 8 人（3、5、11、21、26、28、29、30）用于开发评估。MotionSense 对应为 16 人和 4 人（2、5、14、19）。名单沿用前期开发记录。两库各自的正式预留人员不进入实验。[原始读取及特征代码](../exploration_20261127/pooling/run_pooling.py)
- 目标示范者打乱后两两配对，MotionSense 8 对，UCI 7 对，UCI 有 1 人参与两对。每对模拟 30、60 个标注窗，尽量在动作及两位示范者间均分。各采集方案复用同一人同一类的随机窗口顺序。每窗 2.56 秒，在各人各类的原始窗口序列中每隔一窗建立候选池，避免连续滑窗大量重复。预算表示标注窗数，未计入招募、换动作、爬楼和连续采集的实际耗时。每人每次只有少量原始录制，窗口数也不等于独立试次数。
- 输入是相同的 13 维惯性统计特征，主实验使用 L2 正则逻辑回归。分层模型先判动静，再分别识别三个动态动作和两种姿态。用目标数据替换相应分类器时，源域的动静判断保持固定。直接从头训练的线性模型只用示范窗拟合标准化与分类器。源域和迁移模型使用源域训练人员拟合的标准化。
- 第二组对照为每种采集方案使用同一种五分类模型，将源域训练窗和目标示范窗加权联合训练。每类总权重相同，采到的动作在两域各占一半，没有采到的动作保留源域监督。另做全目标训练人员基线，说明当前特征和模型还有多少改善空间。
- 首轮先比较只采姿态、只采动态、五类均采；看到首轮结果后增加同算法对照，并探索平地三动作和分别省去一种楼梯的方案。每位验证者先算五类 macro-F1，再等权平均验证人和示范者配对。人员和数据集在不同对照中复用，不能把重复抽取的评估值当成独立测试。

从项目根目录运行 `python -B experiments/activity_budget/pilot.py`。脚本使用现有 NumPy、pandas、scikit-learn、threadpoolctl 环境，输入为 `data/UCI HAR Dataset/train/` 和 `data/MotionSense_A_DeviceMotion.zip`。 [每人及各活动结果](results.csv) · [抽取窗口清单](selections.csv)

## 与已有工作的关系

Thukral 等已研究跨位置、少量目标标签以及向未见人员迁移，并改变每类标注数量。Cvetković 等曾要求新用户示范站、躺、坐，再用同一个人的未标注数据更新模型。目标训练只见部分动作、测试时仍识别所有动作，在机器学习中也已有广义零样本域适配问题。本文的备选贡献是比较实际可以要求志愿者执行的采集方案，并量化省去某个动作对它自身造成的代价；这些文献不足以证明这个选题具有首创性。[Cross-Domain HAR](https://arxiv.org/pdf/2310.14390) · [指定姿态进行个性化](https://dis.ijs.si/mitjal/documents/Cvetkovic-Semi-supervised_learning_for_adaptation_of_human_activity_recognition_classifier_to_the_user-IJCAI-11-STAMI.pdf) · [广义零样本域适配](https://doi.org/10.1016/j.neunet.2023.03.033)
