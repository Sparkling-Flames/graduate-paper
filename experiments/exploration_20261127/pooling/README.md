# 新增口袋手机训练数据，对腰部手机识别有帮助吗？

在本次固定预算的先导实验中，加入 MotionSense 对两套验证数据产生了不同效果。腰部手机 UCI 的平均验证损失上升，前裤袋手机 MotionSense 的未见人员识别大幅改善。

| 验证集 | 训练方式 | Macro-F1 | 标签负对数似然 |
| --- | --- | ---: | ---: |
| UCI，4 人、1,169 窗 | UCI | 84.81% | 0.416 |
| UCI，4 人、1,169 窗 | UCI/MotionSense 各半 | 83.01% | 0.504 |
| UCI，4 人、1,169 窗 | 后续对照：仅混合组的 UCI 半批 | 84.19% | 0.423 |
| MotionSense，4 人、3,374 窗 | UCI | 26.03% | 10.951 |
| MotionSense，4 人、3,374 窗 | UCI/MotionSense 各半 | 81.65% | 0.353 |
| MotionSense，4 人、3,374 窗 | 后续对照：仅混合组的 UCI 半批 | 26.09% | 10.165 |

表中先合并同一验证集人员的窗口，对五类 F1 等权平均，再对三个配对种子等权平均。三个种子的 UCI macro-F1 差值依次为 −5.93、−0.81、+1.34 个百分点，UCI 验证损失均上升。MotionSense 的 macro-F1 差值依次为 +52.81、+58.96、+55.10 个百分点。正反方向都与任务目标有关：关心 UCI 泛化时，混合训练缺乏正向证据；需要在两种手机佩戴环境识别时，覆盖目标环境的训练数据很有价值。

差异集中在具体动作。仅用 UCI 训练时，MotionSense 的走路、站立 F1 均约为零；混合后两类分别达到 76.5%、99.4%，下楼仍为 52.3%。在 UCI 验证上，混合后走路从 92.9% 降至 82.3%，坐和站则分别从 71.8%、75.1% 升至 77.9%、79.8%。

## 数据与可比性

- 共用行走、上楼、下楼、坐、站五类。UCI 沿用官方训练部分的 17 人训练、4 人开发验证；MotionSense 沿用项目的 16 人训练、4 人开发验证。对应训练窗分别为 4,776、12,851。脚本只访问 UCI 的官方训练目录，按 MotionSense 文件名先排除预留人员，再读取 CSV。
- 一窗是 50 Hz 下的 128 个采样点，步长 64。在每个 MotionSense 独立试次内切窗。UCI 使用发布者已切好的窗口。
- 每窗提取 13 维。对人体加速度模长（g）和角速度模长（rad/s）各计算均值、标准差、10% 和 90% 分位数、相邻时刻差的均方根。另取窗内平均重力矢量归一化后各轴分量的绝对值，描述手机姿态。UCI 的重力由总加速度减人体加速度得到；MotionSense 使用 Core Motion 的 `gravity`、`userAcceleration` 和 `rotationRate`。各自传感器及预处理仍有差异，尤其是手机佩戴位置和坐标轴。[UCI 信号说明](https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones) · [MotionSense 作者说明](https://github.com/mmalekzadeh/motion-sense) · [Core Motion](https://developer.apple.com/documentation/coremotion/cmdevicemotion)
- 所有条件固定使用 UCI 训练窗拟合的标准化参数。实验中的 MLP 使用上述 13 维输入，与历史 561 维 UCI 特征实验不可直接比较分数。

## 训练与解释

MLP 为 13→32（ReLU）→5，交叉熵，Adam 学习率 0.001，无权重衰减。种子 42、43、44，每个条件固定 800 次参数更新，取末次模型。每步从每类有放回抽取 20 窗，共 100 窗。每个种子下两个条件从相同初始化开始，且每步共享每类 10 个 UCI 窗；剩余半批分别来自 UCI 或 MotionSense。这样两组训练预算、标签频率一致，混合组的 UCI 样本暴露量减半。

得到首轮结果后，针对“UCI 损失上升是否来自每步少见一半 UCI 窗”补做一个对照。训练前指定三个种子与 800 次更新，每步完整复用混合组同一次抽取的 50 个 UCI 窗。相对这一对照，混合组的 UCI 验证损失分别多了 0.128、0.070、0.043。保持 UCI 样本暴露后，损失恶化仍在。相应 macro-F1 差值为 −6.73、+0.40、+2.79 个百分点，方向依赖种子。这个后续比较同时改变了批量大小（50 对 100）、UCI 对梯度的相对权重和另一半批的数据来源。

MotionSense 训练人员与验证人员独立，但属于同一采集协议。混合组同时获得了来自新人员、新设备环境的标注。只有一种混合比例和一套固定人员划分，不能把收益单独归因于人数、佩戴位置或设备，也不能由此反推原 561 维 MLP 的过拟合成因。

## 复跑

从仓库根目录运行。已在 Python 3.11.7、NumPy 1.26.4、pandas 2.3.1、SciPy 1.11.4、scikit-learn 1.2.2 的 CPU 环境验证。

```powershell
python -B experiments/exploration_20261127/pooling/run_pooling.py
```

[脚本](run_pooling.py)会更新[逐种子、逐人、逐类结果](results.csv)。`subject=all` 表示整套验证人员，`nll` 使用自然对数，`macro_f1` 和 `f1_*` 的单位为 0–1。
